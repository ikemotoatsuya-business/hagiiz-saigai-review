# HagiiZ 災害レビュー：公開の手引き

過去の災害を根拠に、未来の問いに答える場。台帳（Excel）1冊から、全ページを書き出す静的サイトです。
答えと受付は、Googleスプレッドシート1枚に集まります。

---

## 1. フォルダの中身

| 場所 | 中身 |
|---|---|
| `daicho_v2.xlsx` | 台帳。**これが正本**。直すのはここだけ |
| `site/gen.py` | 台帳 → 全ページを書き出す |
| `site/og_image.py` | シェア用の画像（1200×630）を書き出す（gen.py が呼ぶ） |
| `site/config.json` | 公開アドレスと、答えの受け皿のURL |
| `site/templates/` | ページのひな形（20枚） |
| `site/static/` | 見た目（site.css）、動き（site.js）、災害の絵（img/） |
| `site/apps-script/Code.gs` | 答えと受付の受け皿（Google Apps Script） |
| `site/tools/build_daicho_v2.py` | 台帳v1 → v2 の移行（一度きり。もう使わない） |
| `site/tools/add_munis.py` | 全国1,741市区町村の行を台帳に足す（何度実行しても同じ） |
| `site/fonts/` | シェア画像用の日本語フォント（Noto Sans JP、OFL） |
| `requirements.txt` | 書き出しに使う部品（jinja2・openpyxl・pillow） |

## 2. ページを書き出す

```bash
pip install jinja2 openpyxl pillow
cd site

# 試し（自分のパソコンで開いて見る用。リンクが index.html 付きになる）
python3 gen.py ../daicho_v2.xlsx ../out_preview --preview

# 本番（Cloudflare Pages に置く用）
python3 gen.py ../daicho_v2.xlsx ../out_site
```

最後に「36ページを書き出しました（公開する資料 105件、未来への問い 18件、根拠カード 22枚）」のように出れば成功です。
数字はすべて台帳から数えているので、ページどうしで数が食い違うことはありません。

`config.json` の `api` が空のあいだは **試作モード**（答えはその端末にだけ保存され、上に「公開前の試作です」と出ます）。

## 3. 台帳とページの対応

| 台帳のシート | 出てくるページ | 公開のスイッチ |
|---|---|---|
| 災害 | 全体図のファイル、`/saigai/<公開用の名前>/` と下の4ページ | 「サイトの公開」＝する／準備中。準備中は全体図の右に灰色で並ぶだけ（投票などはしない） |
| 法律 | `/hou/<公開用の名前>/`（動画・レッスン・国会の問い・年表） | 「サイトの公開」。「動画URL」にYouTubeのURLを入れると動画が出る（空なら「動画は準備中です」） |
| 改正 | 法律ページの年表 | — |
| 未来への問い | `/toi/<公開用の名前>/` 1問1ページ、全体図、一覧 | 「状態」。「種類」＝教訓／国会、「表示順」で並ぶ |
| 根拠カード | 問いの答えに使うカード、`/saigai/…/konkyo/` | 「確認の状態」 |
| 資料 | `/saigai/…/shiryo/`、カードの出典 | 「公開」＝しない、にすると全ページから消える |
| 数字 | `/saigai/…/suuji/`（資料ごとに違う数字はそのまま並べる） | — |
| レッスン | `/manabu/`、法律ページ | 「状態」 |
| 自治体 | `/chiiki/`（47都道府県＋1,741市区町村） | 「地域防災計画のURL」が空なら「リンク準備中」 |
| 災害×自治体 | 被災した町に「〇〇で被災」の印 | 「コードの確認」 |

### 地域防災計画のURLを入れる

1. 台帳の「自治体」シートを開く
2. 「公式サイトのURL（調べる起点）」から町のサイトに入り、地域防災計画のページを探す（この列はサイトには出ません）
3. 見つけたURLを「地域防災計画のURL」に、確かめた日を「リンクの確認日」に書く
4. ページを書き出し直す

市区町村の一覧は code4fukui/localgovjp（CC0）から作りました。名前やコードが変わったら：

```bash
python3 tools/add_munis.py ../daicho_v2.xlsx localgovjp-utf8.csv
```

このとき「災害×自治体」のコードも名前と照らし合わせ、同じ都道府県で名前が1つに決まるものは自動で直します
（今回、川越町 243434→243442、海津市 212202→212211 を直しました）。

## 4. 答えの受け皿をつくる（Google Apps Script）

1. Googleドライブで新しいスプレッドシートを作る（名前：「HagiiZ 災害レビュー 受付」）
2. 「拡張機能」→「Apps Script」を開き、`apps-script/Code.gs` の中身を全部貼って保存
3. 関数「setup」を選んで ▶実行（初回は権限の確認が出ます。自分のアカウントで許可）
   - シート「答え」「受付」「記録」ができます
   - 通知の送り先は、実行したアカウントのメールになります（変えるときは「プロジェクトの設定」→「スクリプト プロパティ」の `NOTIFY_EMAIL`）
   - 新しい答えを1時間ごとにまとめてメールする仕掛けも入ります
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 出てきた `https://script.google.com/macros/s/…/exec` を `config.json` の `api` に貼る
6. ページを書き出し直す（試作モードの帯が消えます）

### 届くメール

| いつ | 件名 |
|---|---|
| 答えに「問題を知らせる」が押された（その場で非表示になる） | 【災害レビュー】通報で答えを隠しました |
| 資料の提供・問いの提案・団体の申請・リンク切れが届いた | 【災害レビュー】受付：〇〇 |
| 新しい答えがあった（1時間ごと） | 【災害レビュー】新しい答え 〇件 |

### 運営がシートでやること

- 隠した答えに問題がなければ：「答え」シートの「表示」列を `表示` に戻す
- 防災士が取り上げた答え：「採用」列に `採用` と書く（問いのページの先頭に「防災士が採用」の印で出ます）
- 受付：「受付」シートの「対応」列に結果を書く

答えはすぐ載ります。だれかを名指しで責める書き込みは、知らせがあればその場で隠れます（ルールは `/about/#rule`）。
同じ端末からの連続投稿は、10分に5件までに制限しています。

## 5. 公開する（GitHub ＋ Cloudflare Pages）

台帳をGitHubで上書きすると、Cloudflareが自動でページを作り直して公開します。

1. `config.json` の `base_url` に公開アドレスを入れる（例 `https://review.hagiiz.com`）
2. GitHubの**非公開（Private）**リポジトリに、このフォルダの中身を置く（`out_site/` と `out_preview/` は不要）
3. Cloudflare → Workers & Pages → 作成 → Pages →「Gitに接続」→ リポジトリを選ぶ
   - フレームワーク：なし
   - ビルドコマンド：`pip install -r requirements.txt && python3 site/gen.py daicho_v2.xlsx out_site`
   - 出力ディレクトリ：`out_site`
   - 環境変数：`PYTHON_VERSION` = `3.12`
4. 「カスタムドメイン」で公開アドレスをつなぐ
5. 以後の更新：GitHubで `daicho_v2.xlsx` を上書きアップロード（または `config.json` などを編集）→ 1〜2分で反映

`out_site` に入っているもの：

- `_headers`：基本のセキュリティ設定と、画像などのキャッシュ
- `robots.txt`：AIの学習用の収集（GPTBot、ClaudeBot、Google-Extended など）を断り、検索エンジンは許可
- `404.html`：見つからないページ
- `og.png`、`og/<問い>.png`：SNSでシェアされたときの画像

---

## 6. 画像を差し替える

`site/static/img/` の4枚（typhoon / earthquake / tsunami / debris）は、Canvaで作った絵の小さい版を拡大した仮のものです。
Canvaから元の大きさで書き出したら、同じ名前（JPG、縦長 3:4 くらい）で上書きして書き出し直してください。
